## Definition

The standard [[mirzakhani-topological-recursion|Mirzakhani recursion]] kernels $R$ (separating) and
$D$ (non-separating), modified by subtracting the Feynman-diagram region (systole below the
[[systolic-threshold|systolic threshold]]) so that they build only the
[[hyperbolic-string-vertices|string-vertex]] part of moduli space. The subtractions are step
functions in the geodesic lengths:
$$\hat R_{L_1,L_2,L_3}=R_{L_1,L_2,L_3}-L_1\,\theta(L-L_3),$$
$$\hat D_{L_1,L_2,L_3}=D_{L_1,L_2,L_3}-R_{L_1,L_2,L_3}\,\theta(L-L_2)-R_{L_1,L_3,L_2}\,\theta(L-L_3)+L_1\,\theta(L-L_2)\theta(L-L_3).$$
Contracted with the cubic vertex $V_{0,3}$ they define string kernels $\langle R|,\langle D|$ that act
as **scalar multiplicative weights** on the vertex — the factorization that collapses the
nonpolynomial closed SFT EOM to the [[fvm-quadratic-integral-equation|quadratic integral equation]].

## Motivation

A string vertex is only the systole-$\ge L$ region of moduli space; the rest is generated by Feynman
propagators. Using the bare Mirzakhani kernels would double-count that Feynman region. The twisting
removes exactly the propagator contribution, leaving kernels whose iteration reconstructs the string
vertices $V_{0,n}$ and nothing else.

## Key formulas

- The $\theta(L-\cdot)$ subtractions above, with $L$ the systolic cutoff (evaluated at $L_*$).
- In the [[seam-graded-expansion|seam-graded]] bookkeeping these kernels carry the seam cost:
  $\hat R$ opens one seam (B-term, cost $1$), $\hat D$ two (C-term, cost $2$).

## Relations

- Derived from the [[mirzakhani-topological-recursion|Mirzakhani recursion]] restricted to the
  [[hyperbolic-string-vertices|hyperbolic vertex]] region above the [[systolic-threshold]].
- Are the integration kernels of the [[fvm-quadratic-integral-equation]].
